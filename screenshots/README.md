## How to Take Screenshots

### Windows:
- **Snipping Tool**: Win + Shift + S
- **Full Screen**: PrtScn button
- Save as PNG for best quality

### Phone (for SMS):
- Use your phone's screenshot feature
- Or take a clear photo with another device
- Make sure OTP code is visible

## Tips:
- Use high resolution
- Show full browser window with URL
- Keep images clear and readable
- Name files exactly as listed above
